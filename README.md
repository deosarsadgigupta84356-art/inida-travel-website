# inida-travel-website
Travel website built by using web development basics to explore destination, budget required and tour planning

## Features
- Displays information about different travel destinations
- Travel expense calculator based on:
  - Destination
  - Number of people
  - Number of days
  - Type of hotel
  - Food and travel preferences
- Provides estimated cost for planning trips
- Basic user interaction for exploring travel options
- Option for user reviews and feedback (basic implementation)
- Guidance-related section for travel support (tour guide concept)

## Tech Used
- HTML
- CSS
- JavaScript (if used)

## About
This project was built as part of my learning in web development. It helped me understand how to design interactive features like cost calculation and user input handling, along with structuring a complete website.
